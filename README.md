# 코스모 — 나의 우주 탐험 퀴즈

10개의 질문으로 우주 지식을 테스트하는 한국어 퀴즈 웹 앱입니다. 오답 복습과 최고 점수 저장(브라우저 localStorage)을 지원합니다.

빌드 과정이 없는 순수 HTML/CSS/JavaScript 단일 파일(`index.html`) 앱입니다.

## 로컬 실행

`index.html`을 브라우저에서 직접 열거나, 간단한 서버로 실행하세요.

```sh
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 GitHub Pages로 자동 배포합니다.
